HOW THESE FIGURES WERE PRODUCED
  The platform's own VerificationService, FeatureExtractor, AnomalyDetectionService
  and RiskScoringService classes were run, unmodified, over the sample documents
  offline. Text was extracted with the same engines the application uses: the PDF
  text layer for PDFs, Tesseract for images, direct reading for text files. These
  are therefore measurements of the implementation, not estimates of it.

TEST CONDITIONS
  Live registry lookups disabled (app.nppes.enabled=false). The identifiers in the
  sample documents satisfy the CMS check-digit algorithm so that validation can be
  exercised, but they are not issued NPIs, so the live registry holds no record for
  them. Every lookup below therefore resolves from the bundled offline snapshot and
  is stamped OFFLINE_FALLBACK, which is correct and expected.

  Run the end-to-end suite the same way:
      java -jar backend/target/credentialing-platform.jar --app.nppes.enabled=false
      node tools/system-test.mjs
